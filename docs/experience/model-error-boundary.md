# 模型失败信息边界 · 2026-09-28

对应 D2/G1。收尾独立审查发现：普通 `complete()` 在 HTTP 非200、网络失败和响应读取中断时，把上游正文或底层异常拼进公开错误；`sendError`、探索与生成状态随后沿用该信息。状态页的遮盖不足以保护这些普通路径。

使用合成 Key、编码后的同值、合成 URL 密码/query token 复现；没有使用真实密钥，没有向真实模型发请求。三个最小失败检查均先失败，原始记录见 [model-error-red.txt](model-error-red.txt)。
